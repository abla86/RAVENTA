# Roadmap

## Current foundation

- React/Vite frontend
- ASP.NET Core/.NET 8 backend
- Domain project
- Current SQLite persistence
- HMS/security control workflow
- API-backed persistence
- Contribution and security documentation

## Production-readiness work

- Automated CI validation
- Automated tests for critical behaviour
- Authentication and authorization
- Production database configuration and migration strategy
- Observability and structured logging
- Security hardening and dependency maintenance
- Deployment configuration
- Backup/recovery strategy
- Operational documentation
- End-to-end validation of the complete application workflow

The roadmap intentionally does not describe unimplemented functionality as production-ready.
