# Security Policy

## Reporting a vulnerability

Please do not publish credentials, tokens, personal information, patient-identifiable information or exploit details in a public issue.

Use GitHub's private security reporting mechanism when it is available for this repository. Otherwise, contact the maintainer through the public contact channel in the profile/portfolio.

## Scope

Security reports should include enough information to reproduce and assess the issue without exposing sensitive data.

## Project status

Unless a repository explicitly states otherwise, public projects are development/prototype software and must not be assumed to be clinically validated, production-hardened or suitable for handling confidential health information.
