# Collaboration

RAVENTA is open to constructive collaboration around software engineering, health technology, HMS/security workflows, evidence-informed development and practical implementation.

## Ways to collaborate

- Report reproducible bugs through GitHub Issues.
- Propose features or improvements through Issues.
- Submit focused pull requests.
- Review architecture, usability, accessibility and security.
- Contribute documentation and tests.
- Suggest implementation improvements.

## Before contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and [SECURITY.md](SECURITY.md).

Do not submit credentials, secrets, personal data or patient-identifiable information.

## Good first contributions

Useful contributions include documentation, tests, accessibility fixes, UI improvements, validation, error handling and narrowly scoped bug fixes.

## Contact

For normal collaboration, use GitHub Issues or Pull Requests. For security-sensitive matters, follow [SECURITY.md](SECURITY.md).
